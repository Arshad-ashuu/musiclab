# 🎶 MusicLab

MusicLab is a collaborative **music creation platform** that enables musicians to **compose music together using virtual instruments** in real-time and publish their creations publicly on the platform.

🔗 Live Demo: [https://musiclab.onrender.com/](https://musiclab.onrender.com/) ([GitHub][1])

---

## 🚀 Features

✨ Real-time collaboration with other musicians
🎹 Virtual instruments to compose and play music
📀 Ability to publish and share music publicly
🧠 Built with modern web technologies
🔐 Uses Firebase for authentication and real-time syncing
⚡️ Real-time communication powered by Socket.IO

---

## 🧠 Tech Stack

| Layer          | Technology                |
| -------------- | ------------------------- |
| Frontend       | React + Vite              |
| Backend        | Node.js + Express         |
| Database       | MongoDB                   |
| Realtime       | Socket.IO                 |
| Deployment     | Render / Netlify / Vercel |
| Authentication | Firebase                  |

## 📦 Installation

### 🛠 Requirements

Before you begin, make sure you have the following installed:

✔ Node.js (v16+)
✔ npm or yarn
✔ MongoDB instance
✔ Firebase project

---

### 📥 Clone the Repository

```bash
git clone https://github.com/Arshad-ashuu/musiclab.git
cd musiclab
```

---

### 📦 Install Dependencies

```bash
# Server
cd server
npm install

# Client
cd ../src
npm install
```

---

### 📝 Setup Environment Variables

Create `.env` files for both **server** and **client** with:

```plaintext
# Server
PORT=
MONGO_URI=
JWT_SECRET=
FIREBASE_API_KEY=
FIREBASE_AUTH_DOMAIN=
FIREBASE_PROJECT_ID=
FIREBASE_STORAGE_BUCKET=
FIREBASE_MESSAGING_SENDER_ID=
FIREBASE_APP_ID=

# Client
REACT_APP_FIREBASE_API_KEY=
REACT_APP_FIREBASE_AUTH_DOMAIN=
REACT_APP_FIREBASE_PROJECT_ID=
REACT_APP_FIREBASE_STORAGE_BUCKET=
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=
REACT_APP_FIREBASE_APP_ID=
```

---

## 🏁 Running the App

### 🐍 Start Backend Server

```bash
cd server
npm run dev
```

### 🚀 Start Frontend

```bash
cd src
npm start
```

Visit `http://localhost:3000` to see MusicLab in action! 🎧
